# Screenshots

This folder holds Power BI dashboard screenshots. These must be captured manually after
building the dashboard in Power BI Desktop (see `dashboard/HOW_TO_BUILD.md` step 7) — they
cannot be generated automatically since Power BI Desktop is a GUI application.

Expected files (referenced from the main `README.md`):

- `page1_executive_overview.png`
- `page2_customer_insights.png`
- `page3_product_operations.png`

Once added, the placeholders in the main `README.md` will render as real images.
